## QuickChat Application - POE Part 3
### Overview
QuickChat is a Java-Based messaging application developed as part of the Programming POE(Part 3). The application allows users to register, log in, send messages, store messages, search messages, generate reports and manage message records through a console-based interface.
### Features
User Registration
User Login
Messaging Systems
Message Management
Data Storage
Testing

### Technologies Used
Java
Netbeans IDE
JUnit
Gson Library
Git & GitHub
